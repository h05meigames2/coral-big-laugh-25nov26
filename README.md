# One Line, Big Laugh

Entry for the make.fun bounty **"One Line, Big Laugh"** (`u-coral-404-one-line-big-laugh-328fb857`).

A tiny Python program that delivers one single line — and one big laugh. No dependencies, no setup, just run it and read the line out loud.

## The joke

> The hotel charged me $40 for the minibar, so I drank the shampoo out of principle and now I smell like a refund.

## How to run

```bash
python3 main.py
```

That's it. The program prints the one-liner to your terminal — one line in, one big laugh out.
