Entry for the make.fun **One Line, Big Laugh** bounty: exactly one funny line, written to land on a cold read. The joke turns a $40 minibar overcharge into petty revenge — the guest drinks the free hotel shampoo out of principle — and the punch lands on smelling like a refund.

## Run

```bash
python3 main.py
```

This writes the one-line joke to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaults to `/output`).
